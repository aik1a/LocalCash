# S05 — Purchases & Contacts

## Objetivo

Implementar agenda local y compras realizadas/planificadas con detalle.

## Tareas

- CRUD mínimo de contactos.
- Crear compra y detalles de producto/servicio.
- Calcular total desde detalles.
- Estado planificada/realizada.
- Consulta de historial/detalle.
- Vinculación con contactos cuando corresponda.
- Resolver/documentar si realizar compra genera movimiento financiero automático.
- Pruebas y trazabilidad.

## Criterios de aceptación

- Contactos persisten localmente.
- Compra con detalles calcula total consistente.
- Compra futura puede distinguirse de realizada.
- Historial se obtiene de datos persistidos, sin tabla redundante solo para "historial" salvo decisión justificada.

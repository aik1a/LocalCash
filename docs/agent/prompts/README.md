# LocalCash — Banco de prompts para agentes

Estos prompts son **bootstraps**, no sustituyen la documentación del repositorio. Están diseñados para iniciar un chat nuevo con un rol definido y hacer que el agente recupere el contexto vigente desde GitHub.

Uso recomendado:
1. abrir un chat nuevo dentro del Project LocalCash;
2. pegar el prompt del rol;
3. añadir el Task Brief o indicar que el Orquestador debe crear la próxima tarea;
4. no pegar manualmente toda la documentación.

Prompts:
- `ORCHESTRATOR.md`
- `CODER.md`
- `AUDITOR.md`

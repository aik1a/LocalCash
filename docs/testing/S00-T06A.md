# Pruebas S00-T06A

## Comandos
bash tests/domain-checks.sh; bash gradlew --no-daemon --console=plain :app:assembleDebug :app:assembleDebugAndroidTest. Workflow s00-t06a-build.yml valida el SHA exacto, conserva salida, retorno, hash/APK y evidencia.

## Escenarios automatizados
- Dominio: límites geográficos, Santiago, NaN/infinito/rango inválido, constructor anterior y ubicación null.
- Emulador desechable: fixtures genuinos v1/v2/v3 con tablas/filas originales, migración a v4 y comparación de cada valor original, FK, saldo y deudas.
- SQLite: pares incompletos, rango, texto e infinito; INSERT/UPDATE inválidos rechazados.
- Regresión completa de cuentas/movimientos/contactos/compras/deudas mediante FlowChecks; su fixture histórico v2 retira las columnas v4 solo en la BD de pruebas antes de migrar.
- Registro sin optar por ubicación no solicita permisos y persiste NULL.
- Denegación desde el diálogo real de Android permite guardar sin ubicación.
- Permisos concedidos mediante pm grant y GPS de emulador enviado con adb emu geo fix -70.66 -33.45 ejercitan LocationManager y UI productivos.
- Consentimiento retirado tras capturar elimina el par antes de guardar.
- Ubicación desactivada mediante cmd location y proveedor Android de pruebas sin fix: estado visible y timeout real de 15 segundos; registro sin coordenadas. El proveedor de pruebas ejercita la API Android/listener productivo, no reemplaza repositorio ni flujo UI.
- Reapertura y force-stop/relanzamiento: un nuevo movimiento geolocalizado, cinco nuevos sin ubicación y saldo 131,50 conservados; capturas/XML.

## Limitaciones y seguridad del fixture
Fixtures eliminan/recrean localcash.db exclusivamente en emulador desechable. No ejecutar Instrumentation sobre instalaciones con datos de usuario. CI no equivale a GPS físico ni a actualización de APK con el certificado anterior; estos siguen para T07.

La captura espera una actualización del proveedor; no lee coordenadas cacheadas. GPS funciona sin servicios externos; si solo hay permiso aproximado se intenta proveedor de red disponible sin convertirlo en requisito para registrar. Maps/biometría fuera de esta tarea.

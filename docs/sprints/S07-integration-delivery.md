# S07 — Integration & Delivery

## Objetivo

Integrar, probar, corregir y preparar una entrega reproducible y defendible.

## Tareas

- Ejecutar matriz completa de requisitos/pruebas.
- Corregir defectos bloqueantes y regresiones.
- Revisar funcionamiento offline de las funciones principales.
- Revisar build desde checkout limpio.
- Congelar dependencias y documentarlas.
- Completar guía BUILD.
- Completar documentación técnica y diagramas finales.
- Preparar pauta de exposición/demo.
- Auditoría final de trazabilidad y alcance.

## Criterios de aceptación

- Los cuatro pilares obligatorios son demostrables.
- Build reproducible.
- Documentación coincide con el código.
- Ningún requisito obligatorio queda sin evidencia o explicación explícita.
